# Bezug

Link auf eine Person, ein Team oder einen Vorgang mitten im Text – führt zur Detailseite.

- Konsument gibt Namen als Kinder, `href`, `art` (Person/Team/Vorgang, erscheint als Tooltip).
- Kein Avatar, kein Chip, keine Farbe: der Name reicht. Unterstrich in `line-control`, Hover in `accent`.
- In Quittungen zeigt ein Bezug, *was* das System erkannt hat – so wird eine Fehlzuordnung sichtbar.

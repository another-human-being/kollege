# Leer

Leerer Zustand in Worten: ein Satz, was hier stehen würde, und wie es dahin kommt.

- Konsument gibt `titel` (Aussagesatz mit Punkt), `text` (wann hier etwas erscheint), optional `aktion`.
- Keine Illustrationen, keine Emojis, kein „Hurra“. Leer ist ein normaler, guter Zustand.
- Ein leerer Abschnitt bleibt sichtbar – er beantwortet eine Frage („Wartet etwas auf uns?“ – „Nein.“).

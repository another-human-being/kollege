# Hinweis

Ein Eintrag der Übersicht: was ansteht, warum, woher wir das wissen, und was das System anbietet.

Aufbau (von oben): Zeitspalte links (`col-date`, Mono) · Titel als ganzer Satz mit `Bezug` · Kontextzeile (`Etikett`, Vorgang, zuständige Person) · Gründe als `Aussage`n · optionale Frage · Aktionen.

- Konsument gibt `zeit`, `titel`, `kontext`, `gruende` (`[{art, text, quelle, dringend}]`), `frage`, `aktionen`, `dringend`.
- Mindestens ein Grund. Ein Hinweis ohne Grund wird nicht gezeigt.
- Titel ist ein Aussagesatz mit Punkt, Wer zuerst: „Solaro hat das Pitchdeck nicht geschickt.“ Der Kern in `body-strong`.
- Fragen in der Ich-Form des Systems: „Soll ich nachfragen?“ Nie „Möchten Sie…“.
- `dringend` färbt nur die Zeitspalte in `attention`. Kein farbiger Balken, kein Hintergrund.
- Was nach außen ginge, erscheint als Aktion „Entwurf ansehen“ oder direkt als `Entwurf` darunter.
- Mobil: Zeitspalte rückt über den Titel.

# Wissensluecke

Ehrlicher Zustand statt geratener Antwort: „Dazu habe ich noch zu wenig Erfahrung.“

- Konsument gibt optional `titel`, `bekannt` (was das System weiß und warum es nicht reicht) und `aktionen` (wen man fragen kann, wie man die Lücke füllt).
- Immer dann, wenn eine Antwort nur aus Vermutung bestünde. Eine Vermutung darf neben Belegen stehen (`Aussage` mit KI-Vermutung), aber nie allein eine Frage beantworten.
- Zeichen ∅, Text in `ink`, Erklärung in `ink-muted`. Keine Entschuldigung, kein „Leider“.

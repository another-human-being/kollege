# Anweisung

Eine Regel in Alltagssprache, die das System befolgt. Die Liste auf `/anweisungen` besteht nur aus diesen.

- Konsument gibt Text, `geltung` (`team` · `persoenlich`), `von`, `datum`, `angewandt` (berechnet), `onBearbeiten`, `onLoeschen`.
- Die Liste liegt in den Einstellungen. Neue Anweisungen entstehen meist im Chat und werden dort mit einer `Karte art="anweisung"` bestätigt.
- Text in Anführungszeichen: es sind die eigenen Worte des Teams, nicht übersetzt in Regeln.
- „= 4× angewandt“ macht nachprüfbar, ob eine Anweisung wirkt; ein Klick zeigt, wo.
- Neue Anweisungen entstehen über das Eingabefeld („Ab jetzt: …“) oder direkt hier.

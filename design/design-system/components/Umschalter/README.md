# Umschalter

Zwei bis drei gleichrangige Ansichten, z. B. „Meins / Team“ auf der Übersicht.

- Konsument gibt `optionen`, `wert`, `onWechsel`.
- Graue Spur (`paper-sunk`), aktive Option als weiße Pille mit Haarlinie (E54). Die Wahl wird pro Person gemerkt.
- Nicht für Filter mit vielen Werten – dafür die Filterzeile der Liste.

# Aktion

Knöpfe und Textaktionen. Vier Varianten, jede mit fester Bedeutung.

- `primaer` (Fläche `accent`, Text `on-accent`): nur „Senden“ und „Merken“ – eine pro Bereich. Es ist die Handlung, die ein Mensch bewusst auslöst.
- `sekundaer` (Rahmen `line-control`): „Ansehen“, „Übergeben an…“, Antwortknöpfe in Klärungen.
- `text`: leise Nebenaktionen („Falsch zugeordnet?“, „Bearbeiten“, „Alle ansehen“).
- `rueckgaengig`: mit ↶, hinter allem, was das System selbst getan hat. Ein Klick, keine Rückfrage; danach Hinweis „Rückgängig gemacht · Wiederholen“.
- Verben im Infinitiv oder Imperativ, ein bis zwei Wörter. Nie „OK“, nie „Bestätigen“.
- Mindesthöhe 32px Desktop, 44px mobil.

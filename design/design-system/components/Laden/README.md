# Laden

Laden als ehrlicher Text: was gerade gelesen wird und wie weit. Keine Spinner, keine Skelett-Blöcke.

- Konsument gibt `text`, optional `wert`/`max` (zeigt Zähler und eine 1px-Spur), oder `inline` für kurze Wartezeiten in einer Zeile.
- Zahlen mit deutschem Tausenderpunkt, tabellarisch.
- Die Auslassungspunkte atmen langsam; bei `prefers-reduced-motion` stehen sie still.
- Längere Vorgänge (Einrichtung) laufen im Hintergrund weiter; die Seite bleibt benutzbar.

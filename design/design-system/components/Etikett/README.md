# Etikett

Art eines Vorgangs als schlichtes Etikett: Beratung, Event, Beitrag, Lehre, Sonstiges. Auch für „Team“/„Persönlich“ bei Anweisungen.

- Konsument gibt `art` (`beratung` · `event` · `beitrag` · `lehre` · `sonstiges`) oder eigenen Text.
- Pille mit Haarlinie auf `surface` (E54). Bewusst farblos. Arten bekommen keine Farbcodes – Farbe ist für Handlungsbedarf reserviert (`accent`, `attention`).
- Ein Etikett pro Vorgang. Keine Tags-Wolken.

# Quelle

Verweis auf den Beleg, aus dem eine Aussage stammt: Kanal + Datum, in Mono, gepunktet unterstrichen, öffnet den Beleg.

- Format: `Mail 12.09.`, `Notiz Julia 24.09.`, `Termin 20.11.`, `Dateiname.pdf`. Kein Wochentag, kein Jahr im laufenden Jahr, keine Uhrzeit außer am selben Tag.
- Konsument gibt Text und `href` oder `onClick` (öffnet Beleg in der Seitenleiste).
- Jede belegte Aussage hat genau eine Quelle. Mehrere Belege: die jüngste zeigen, Rest im Vorgang.

`Bezug` (in derselben Vorschau) verlinkt Personen, Teams und Vorgänge im Fließtext: normale Schrift, Haarlinien-Unterstrich.

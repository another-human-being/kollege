# Nachricht

Eine Zeile im Chat. Der Chat ist ein Logbuch: wer und wann links in der Zeitspalte, Text rechts.

- Konsument gibt `von` (`du` · `kollege`), `zeit`, Text als Kinder, `streamt` (Schreibmarke während die Antwort entsteht).
- Keine Sprechblasen, keine Avatare, keine Farben pro Sprecher. „Du“ steht in `ink`, „Kollege“ in `ink-muted`; eigene Nachrichten sind eine Stufe größer (17/26), weil sie der Anlass sind.
- Faktische Sätze des Kollegen tragen eine `Quelle` direkt nach dem Satz. Deutungen stehen nicht im Fließtext, sondern als `Aussage art="einschaetzung"` (mit KI-Vermutung) darunter.
- Was das System dabei im Record abgelegt hat, folgt als `Karte`, nie als Satz („Ich habe eingetragen …“ reicht nicht – es braucht die Karte mit Rückgängig).

# Navigation

Obere Leiste als Schrägstrich-Pfade: `/übersicht /vorgänge /personen /klärung 3 /anweisungen`.

- Konsument gibt `eintraege` (`label`, `href`, `aktiv`, `anzahl`) und optional `rechts` (Name der angemeldeten Person).
- `anzahl` nur für Dinge, die auf eine Entscheidung warten (offene Klärungen). Sie steht in `attention`, weil sie Arbeit bedeutet – keine Zähler für Neuigkeiten.
- Labels klein geschrieben, wie Pfade. Keine Icons.
- Mobil: die Liste scrollt waagerecht; die Marke bleibt.

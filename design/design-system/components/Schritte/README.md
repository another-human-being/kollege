# Schritte

Zeigt, was Kollege für eine Antwort getan hat: gelesen, gesucht (mit Fundstellen als Chips), gefunden – oder dass es nichts Belastbares gibt. Steht im Chat direkt vor der Antwort.

- Konsument gibt `schritte` (`[{art, text, funde}]`); `art` ∈ lesen · suche · gefunden · luecke.
- Icons links an einer senkrechten Haarlinie, Text in `ink-muted`, Fundstellen in Mono als graue Chips.
- Höchstens drei bis vier Schritte; nur echte Arbeitsschritte, kein Füllstoff („denke nach …“).
- Ersetzt nicht die Belege: Die Antwort trägt ihre Quellen weiter als `Aussage`/`Quelle`.

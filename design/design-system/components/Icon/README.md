# Icon

Linien-Icon, 16 px, Strich 1,6, Farbe wie der Text (`currentColor`). Eigene, einfache Geometrie – keine Icon-Bibliothek.

- Nur in Navigation, Clusterköpfen, Suche und Aktionsleisten; immer mit Wort daneben oder als Knopf mit Tooltip und `aria-label`.
- Im Fließtext kein Icon außer dem Schloss (`Privat`).
- Bausteinsatz: hoch, lesen, suche, gefunden, luecke. Die Navigations-Icons der App (heute, chat, mail, kalender …) folgen derselben Geometrie.

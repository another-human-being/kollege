# Privat

Kleines Schloss: Dieser Eintrag ist nur für dich sichtbar. Das einzige Piktogramm im System.

- Konsument gibt Text (Standard „privat“) oder `nurSymbol` (Schloss allein, Screenreader liest „privat, nur für dich“).
- `fuer`: gehört der Eintrag jemand anderem, nennt das Schloss sie („nur Julia“, Tooltip „Privat: nur für Julia sichtbar“). Ohne `fuer` heißt es „nur für dich“.
- Für Notizen und Verlaufseinträge, die jemand als privat markiert hat, und als Hinweis „Chats sind persönlich“.
- Private Einträge zählen für Hinweise und Fristen nur für ihre Besitzerin. In Team-Ansichten sieht nur die Besitzerin sie (mit Schloss).
- Kein Schloss ohne Wort in der Nähe – beim ersten Auftreten auf einer Seite steht „privat“ dabei.

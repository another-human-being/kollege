# Zusage

Eine offene Zusage – von uns oder vom Gegenüber – mit Frist und Quelle. Im Vorgang in zwei Spalten: „Wir“ und der Name der anderen Seite.

- Konsument gibt Text, `status` (`offen` ○ · `ueberfaellig` ! · `erledigt` ✓), `faellig`, `quelle`.
- Überfällig: Zeichen und Frist in `attention`, Wort „fällig“ bleibt stehen. Erledigt: durchgestrichen in `ink-muted`, bleibt eine Woche sichtbar.
- Zusagen entstehen aus Eingaben und Mails; eine Zusage ohne Quelle gibt es nicht.

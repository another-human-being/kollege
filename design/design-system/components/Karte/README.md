# Karte

Kompakte Quittung im Chat: was das System gerade im Record abgelegt hat – mit Link zum Vorgang und Rückgängig.

- `art`: `quittung` (Titel „Erledigt“) oder `anweisung` (Titel „Anweisung gespeichert“, dazu `geltung` `persoenlich` · `team`).
- Konsument gibt `punkte` (je ein Satz, was passiert ist), `linkText`/`linkHref` (Vorgang oder Anweisungsliste), `anweisung` (angewendete Anweisung, erscheint als „nach Anweisung: …“), `folgen`, `privat`, `onRueckgaengig`, `onWiederholen`.
- **Folgeschritte immer nennen.** Wenn Rückgängig mehr entfernt als den ersten Punkt, steht das neben dem Knopf in `attention`: „entfernt auch 1 Aufgabe“. Nie still mitlöschen.
- Oben eine Linie in `ink`, kein Rahmen: die Karte ist ein abgeschlossener Beleg im Record, nichts, das nach außen geht.
- Nach Rückgängig: Punkte durchgestrichen, „Rückgängig gemacht · Wiederholen“. Die Karte bleibt im Chat stehen.
- Punkte nennen nur interne Schritte. Was nach außen ginge, ist ein `Entwurf` darunter.

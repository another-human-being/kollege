# Abschnitt

Gliedert die Übersicht in „Heute“, „Wartet auf uns“, „Wir warten auf“, „Hängt“ – Versalien-Label, Zahl in Mono, Haarlinie.

- Konsument gibt `titel`, `anzahl`, optional `aside` (z. B. `Umschalter` Meins/Team) und die Einträge als Kinder.
- Ohne Kinder zeigt der Abschnitt `leer` – immer einen `Leer`-Zustand mitgeben, nie den Abschnitt ausblenden. Ein leerer Abschnitt ist eine gute Nachricht und soll gelesen werden.
- Höchstens fünf Einträge; der Rest hinter „Alle 12 ansehen“ (`Aktion` Variante `text`).
- Abstand zwischen Abschnitten: `space-6`.
